One memory for all your AI tools.

Anamnesis imports your history from Claude Code, Codex, Cursor, Gemini and ChatGPT into one local database, then lets every agent search it over MCP.

pip install -e . && anam sync 
$ anam sync
imported 44 conversations, 5,906 messages

$ anam connect claude-code
✓ claude-code connected

$ anam search "why did we drop redis"
codex · api-server · Mar 4
  Redis only held sessions; moved them to SQLite…

How it works

Import

Reads the transcripts your AI tools already keep on disk. Re-running only picks up what changed.

Search

Keyword and semantic search with local embeddings. Filter by tool or project.

Share

An MCP server gives every connected agent the same memory. Optional encrypted sync between your computers.

Commands

anam syncImport new history from local AI tools
anam import <files>Import ChatGPT, claude.ai or Gemini exports
anam search <query>Search memory
anam connect [tool]Register the MCP server with Claude Code, Claude Desktop, Cursor, Gemini CLI or Codex. Configs are backed up first.
anam share · anam joinSync memory across computers through iCloud or any synced folder
anam statusWhat is stored and which tools are connected

Privacy

Everything lives in ~/.anamnesis on your machine. No account, no server. Sync files are encrypted before they leave your computer.
