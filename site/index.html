01 · Import

Everything you've already said to an AI, in one place

NexusAI reads the transcripts your tools already keep on disk. Only files that changed are re-read, and nothing is imported twice.

  • Claude Code, Codex, Gemini CLI and Cursor, read in place
  • ChatGPT, claude.ai and Gemini web via their data exports
  • Noise stripped: tool calls, system reminders, sidechains

02 · Search

Ask by meaning, filter by tool or project

Hybrid search pairs full-text with local embeddings, so “that thing about the staging lock” finds the right answer in any tool, from any week.

  • Semantic and keyword search, ranked together
  • Scope by source, project folder, or thread
  • Terminal UI, web UI and CLI all share one store

03 · Recall

Every agent remembers what the others learned

One command registers NexusAI as an MCP server in each tool. Your agents look things up before asking you, and save decisions as they make them.

  • nexus connect all edits configs safely, with backups
  • Open sessions see new memories within a minute
  • Notes written in one tool show up in every other

Every computer

New laptop. New account. Same memory.

Pair your machines with one code. Each computer writes its own encrypted log to a folder you already sync (iCloud, Dropbox or Syncthing) and reads everyone else's. No server, no conflicts, and nothing your cloud provider can read.

$ nexus sharefirst computer · prints a pairing code
$ nexus join K7QF-…every other computer

Local-first isn't a setting. It's the architecture.

Your memory is a SQLite file and a vector index in your home folder. Read it, back it up, delete it.

Stays on your machine

Everything lives in ~/.nexus-ai. Embeddings run locally on your CPU. No account, no telemetry.

Encrypted end to end

Sync is AES-256-GCM. The key exists only in your pairing code, never in the synced folder.

Your keys, if any

Memory needs no API key at all. The optional chat side uses your own keys from .env.

Context that follows you across every tool.

One MCP server, registered everywhere with a single command.
