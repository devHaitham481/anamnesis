    ii. How it works

    Three verbs. That's the product.

    Import

    Read what happened

    Transcripts from every tool on this machine land in one SQLite file. Only changed files are re-read, and nothing is stored twice.

    Recall

    Search by meaning

    Full-text and local embeddings, ranked together. Filter by tool, project or thread, from the terminal, the web UI or any agent.

    Share

    Give it to every agent

    One MCP server, registered with a single command, so each tool reads and writes the same memory.

    iii. Every agent

    Ask once. Every agent knows.

    Agents look things up before asking you, and write down decisions as they make them. Switch tools mid-task without re-explaining a thing.

    • search_memory, recent_conversations, get_conversation, remember
    • anam connect all registers it everywhere and backs up every config it touches
    • Sessions already open see new memories within a minute
    iv. Every computer

    New laptop. Same memory.

    Pair your computers with one code. Memory travels through a folder you already sync, encrypted so the cloud can't read it.

    • Each computer writes only its own log, so there's nothing to conflict
    • AES-256-GCM; the key lives in your pairing code, never in the folder
    • iCloud Drive by default, Dropbox or Syncthing too. No server of ours

    v. Yours

    It's just a folder.

    A SQLite file and a vector index in your home directory. Read it, back it up, delete it.

    • Embeddings run on your CPU. No account, no telemetry, no API key
    • Your own keys from .env are used only if you chat inside Anamnesis
    • Terminal UI, web UI and CLI all read the same store
